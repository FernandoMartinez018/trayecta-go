# Trayecta Go

**Sal a tiempo, llega seguro.** App de rutas para motociclistas y domiciliarios en Bogotá y la Sabana: calcula a qué hora salir para llegar cuando quieres, adapta la ruta a la moto y avisa de alertas reportadas por la comunidad.

| Carpeta | Contenido |
|---|---|
| `contratos/` | API REST (OpenAPI 3.1) y eventos (AsyncAPI 3) |
| `backend/` | Kotlin + Ktor |
| `app/` | Kotlin Multiplatform (Android primero) |
| `web/` | Landing y política de privacidad |
| `diseno/` | Tokens del sistema de diseño |
| `entorno-local/` | Servicios para desarrollo con Docker Compose |

Despliegues en el repositorio `trayecta-go-infra`.

Para trabajar con Claude Code, la guía está en [`CLAUDE.md`](CLAUDE.md). La documentación del proyecto (decisiones, backlog, diseño, arquitectura y bitácora) se mantiene fuera del repositorio, en la carpeta local de Fernando.
